## 🚀 Quick Start & Empirical Replication

### 1. Replicating Phase 1 (Foundational Logic Gates & XOR)
```bash
# Clone the repository
git clone https://github.com/pCwOrM/mandelbrot-fractal-neural-synthesis.git
cd mandelbrot-fractal-neural-synthesis

# Install minimal dependencies
pip install -r requirements.txt

# Verify discrete linear logic gates (AND, OR, NAND, NOR -> 100% accuracy)
python -m src.fractal_neuron

# Verify composite non-linear XOR solution (100% accuracy)
python -m src.xor_composite_network

# Run resolution Pareto trade-off curve (32x32 to 256x256)
python -m src.benchmark_resolutions
```

### 2. Replicating Phase 3 (Orbital Error Dynamics & 5-Seed Benchmark)
```bash
# Run the 5-seed empirical benchmark with 80/20 train/test split
python experiments/simulate_oed_rigorous.py

# Run mathematical simulation of cusp drag, tunneling, and phase surfing
python experiments/simulate_oed_math.py

# Regenerate all 7 scientific publication vector figures (300 DPI)
python scripts/generate_clean_scientific_figures.py
```

# On Windows:
start index.html

start demos/quadrant_visualizer.html
start demos/snake.html

open index.html
