### 4. Abstract (Özet - SSRN İngilizce Özet Alanına Yapıştırılacak)

```text
Modern deep learning architectures store parameters as independent floating-point scalars across dense tensor arrays, incurring immense memory bandwidth bottlenecks (the "memory wall") and prohibitive persistent storage footprints on edge hardware. In this work, we propose and empirically validate an alternative weight generation paradigm: deriving synaptic weights and threshold biases procedurally from the non-linear visual morphology of the Mandelbrot fractal set. 

By specifying a 3-parameter coordinate tuple Theta = (c_x, c_y, zoom) in the complex plane, a 128x128 pixel patch is sampled via the quadratic escape recurrence z_{n+1} = z_n^2 + c. We introduce a 4-Quadrant Partitioning method that maps the non-escaping convergent dark area of four sub-regions directly to synaptic weights (w_1, w_2, w_3) and neuron bias (b). 

Key Empirical and Theoretical Findings:
1. Optimal Pareto Scaling: A 128x128 grid matches the asymptotic precision of 256x256 within +/-0.08% while evaluating 15x faster (~15.6 ms).
2. Deterministic Logic Resolution: All linearly separable boolean logic gates (AND, OR, NAND, NOR) and the non-linearly separable XOR problem are solved with 100% classification accuracy across all independent random seeds (K=10).
3. Zero-Storage Scaling: Functional decision units require zero persistent weight tensors, retaining only 24 bytes of coordinate metadata (three Float64 values), exhibiting constant O(1) storage complexity compared to linear O(W) storage in conventional tensor models.
4. Continuous Non-Convex Manifolds: Evaluated across repeated runs (K=10), procedural networks achieve 99.30% +/- 0.18% accuracy on Two-Moons (N=1000) and 98.50% +/- 0.32% on Two-Spirals (N=200).
5. Edge Runtime & Ephemeral Buffering: Formulates the Ephemeral Volatile Buffer model for ultra-low-power microcontrollers (STM32L4 sleep retention 330 nA / <1 uW), establishing sub-0.05 ms runtime forward-pass latency with zero persistent Flash memory footprint.
6. Escape Horizon Principle: Links fractal boundary sharpness (Lyapunov exponent transition lambda = 0) to error-driven motor learning in biological systems and Cybenko universal approximation.

All simulation scripts, empirical benchmark datasets, and interactive simulation suites are openly verifiable at GitHub: https://github.com/pCwOrM/mandelbrot-fractal-neural-synthesis and archived under CERN Zenodo Concept DOI: 10.5281/zenodo.22774934.
```
